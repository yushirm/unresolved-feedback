# UNRESOLVED public beta feedback

This is the public issue tracker for the **UNRESOLVED** public beta. The game
and its source project are separate from this repository.

## Issues only

This repository is deliberately limited to player reports and discussion in
GitHub Issues. It is not a source-code mirror and does not accept code, asset,
story, configuration or documentation contributions. Pull requests will be
closed without merging.

Only the project owner administers the tracker files. The default branch is
locked, GitHub Actions are disabled, and public users cannot push commits to
this repository.

- [Report a bug](https://github.com/yushirm/unresolved-feedback/issues/new?template=bug.yml)
- [Share general feedback](https://github.com/yushirm/unresolved-feedback/issues/new?template=feedback.yml)
- [Play the beta](https://playunresolved.vercel.app/)

Bugs, observations and suggestions are welcome. This tracker is public:
please do not include personal, confidential or sensitive information. Never
post passwords, account credentials, private save files or anything you do not
want visible on the internet.
