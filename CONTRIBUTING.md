# Contributing feedback

UNRESOLVED feedback is accepted through the structured GitHub Issue forms in
this repository.

- Use **Bug report** for reproducible problems.
- Use **General feedback** for observations and suggestions.
- Do not open pull requests or submit code, game assets, story content,
  configuration files or documentation changes. They are not accepted here.
- Do not upload source code, save files, diagnostics or screenshots containing
  personal, confidential or sensitive information.
- Keep reports relevant to the UNRESOLVED public beta. Duplicate, unsafe,
  abusive, promotional or unrelated material may be edited, locked or closed.

The playable game and its private source project are separate from this public
tracker. Filing an issue does not grant repository write access.
